# drafts/ — your working folder

This is where you write. **Nothing here gets committed to git** except this README
and `notes.template.md` (see `.gitignore`), so your actual essays and notes stay
local to your session and never land in GitHub history.

## How to start an essay

1. Copy the template into a real file, named for the essay:
   `cp notes.template.md commonapp.md` (or `stanford-whyus.md`, etc.)
2. Brain-dump into it — messy is the point. Don't shape it yet.
3. Run `/draft` and point the coach at the file.

Because these files are git-ignored, they won't survive the container being
reclaimed. If you want to keep a draft between sessions, copy it somewhere tracked
or download it — just know that means it enters git history / leaves your machine.
