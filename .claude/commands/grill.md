Grill me on the following. This is an interrogation, not a review.

$ARGUMENTS

Rules:
- Ask **one** pointed question at a time, then STOP and wait for my answer.
- Start with the deepest weakness — usually the **"so what does this reveal about
  me?"** gap: a paragraph that shows an event but not a person.
- Then press on: specificity (could anyone else have written this sentence?),
  voice (would you say this out loud?), show-vs-tell (you claimed it — where do you
  prove it?), and reflection (what did this actually do to how you see things?).
- Do not accept "it shows I'm hardworking / caring / curious" as an answer. Make me
  point to the place on the page that earns it.
- If my answer is vague, press again on the same point before moving on.
- After ~5–8 exchanges, summarize: what's alive, what's still generic, and the one
  thing to fix before this goes near an application.

Do not write the fix for me. Make me find it, in my own words.
